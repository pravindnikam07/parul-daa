# 1. Real-World Motivation

Imagine you are using **Google Maps**.

You want to travel from:

**College → Railway Station**

Google Maps doesn't care about connecting every location in the city.

It only wants the **shortest route from your current location to the destination**.

This is called the **Shortest Path Problem**.

Dijkstra's Algorithm efficiently solves this problem when all road lengths (edge weights) are **non-negative**.

---

# 2. Everyday Analogy

Imagine water flowing through pipes.

You pour water at one source.

Water naturally reaches nearby locations first.

Then slightly farther locations.

Eventually, it reaches every reachable location.

Dijkstra's Algorithm behaves similarly—it expands outward from the source in increasing order of distance.

# 3. What is the Shortest Path Problem?

Given:

- A weighted graph
- A source vertex

Find the **minimum distance** from the source to every other vertex.

Example:

```text
        4
   A -------- B
   |          |
 2 |          | 5
   |          |
   C -------- D
        3
```

If Source = A

Answer:

| Vertex | Distance |
| ------ | -------: |
| A      |        0 |
| B      |        4 |
| C      |        2 |
| D      |        5 |

Notice

Shortest path to D is

```text
A → C → D

2 + 3 = 5
```

instead of

```text
A → B → D

4 + 5 = 9
```

# 4. Shortest Path vs Minimum Spanning Tree

This is one of the most commonly confused concepts.

| Minimum Spanning Tree      | Shortest Path                       |
| -------------------------- | ----------------------------------- |
| Connects all vertices      | Finds shortest path from one source |
| Minimizes total edge cost  | Minimizes distance from source      |
| Uses Prim/Kruskal          | Uses Dijkstra                       |
| Total network cost matters | Individual path cost matters        |
| Every vertex connected     | Destination may be one or many      |

# 5. Why Not Use BFS?

Students often ask:

Why not simply use BFS?

Answer:

BFS assumes

Every edge has equal cost.

Example

```text
A ---- B

Cost = 10

A ---- C

Cost = 1

C ---- B

Cost = 1
```

BFS chooses

```text
A → B

Cost = 10
```

Dijkstra chooses

```text
A → C → B

1+1 = 2
```

Hence,

BFS fails for weighted graphs.


```text

```

# 7. Key Idea

At every step

Choose

> The **unvisited vertex having the smallest known distance**.

This is the Greedy choice.

# 8. Important Concept: Relaxation

Relaxation is the heart of Dijkstra's Algorithm.

## Definition

Relaxation means checking whether going through one vertex provides a shorter path to another vertex.

Formula

```text
If

distance[u] + weight(u,v) < distance[v]

then

distance[v] = distance[u] + weight(u,v)
```

---

# Example

Current

```text
Distance(C)=2

Edge

C → D =3

Distance(D)=10
```

New distance

```text
2+3=5
```

Since

```text
5<10
```

Update

```text
Distance(D)=5
```

This process is called **Relaxation**.

# 13. Why Does Dijkstra Work?

When a vertex with the **minimum tentative distance** is selected,

there cannot be another shorter path to that vertex (provided all edge weights are non-negative).

Therefore,

its shortest distance is finalized.

This is why Dijkstra uses a **Greedy strategy**.

---

# 14. Why Dijkstra Fails for Negative Edge Weights

Consider

```text
A ---- B = 4

A ---- C = 5

C ---- B = -3
```

Dijkstra first finalizes

```text
B = 4
```

Later

```text
A → C → B

5 + (-3)=2
```

Actual shortest distance is

```text
2
```

But Dijkstra already finalized

```text
4
```

Hence,

the algorithm gives an incorrect result.

---

# Important Note

Dijkstra's Algorithm works only when

**All edge weights are non-negative.**

For negative edge weights,

use

```text
Bellman-Ford Algorithm
```

# 15. Java Implementation

```java
import java.util.*;

class Pair {
    int vertex;
    int distance;

    Pair(int vertex, int distance) {
        this.vertex = vertex;
        this.distance = distance;
    }
}

public class Dijkstra {

    static final int V = 4;

    static void dijkstra(int[][] graph, int source) {

        int[] distance = new int[V];
        boolean[] visited = new boolean[V];

        Arrays.fill(distance, Integer.MAX_VALUE);

        distance[source] = 0;

        PriorityQueue<Pair> pq =
            new PriorityQueue<>(Comparator.comparingInt(a -> a.distance));

        pq.offer(new Pair(source,0));

        while(!pq.isEmpty()){

            Pair current = pq.poll();

            int u = current.vertex;

            if(visited[u])
                continue;

            visited[u]=true;

            for(int v=0;v<V;v++){

                if(graph[u][v]!=0 && !visited[v]){

                    int newDistance =
                        distance[u]+graph[u][v];

                    if(newDistance<distance[v]){

                        distance[v]=newDistance;

                        pq.offer(new Pair(v,newDistance));
                    }
                }
            }
        }

        System.out.println("Shortest Distances");

        for(int i=0;i<V;i++)
            System.out.println(i+" : "+distance[i]);
    }

    public static void main(String[] args){

        int[][] graph={
                {0,4,2,0},
                {4,0,0,5},
                {2,0,0,3},
                {0,5,3,0}
        };

        dijkstra(graph,0);
    }
}
```

# 16. C++ Implementation

```cpp
#include<iostream>
#include<vector>
#include<queue>

using namespace std;

const int V=4;

void dijkstra(vector<vector<int>> &graph,int source){

    vector<int> distance(V,INT_MAX);

    vector<bool> visited(V,false);

    priority_queue<pair<int,int>,
            vector<pair<int,int>>,
            greater<pair<int,int>>> pq;

    distance[source]=0;

    pq.push({0,source});

    while(!pq.empty()){

        auto current=pq.top();

        pq.pop();

        int u=current.second;

        if(visited[u])
            continue;

        visited[u]=true;

        for(int v=0;v<V;v++){

            if(graph[u][v]!=0 && !visited[v]){

                int newDistance=
                    distance[u]+graph[u][v];

                if(newDistance<distance[v]){

                    distance[v]=newDistance;

                    pq.push({newDistance,v});
                }
            }
        }
    }

    cout<<"Shortest Distances\n";

    for(int i=0;i<V;i++)
        cout<<i<<" : "<<distance[i]<<endl;
}

int main(){

    vector<vector<int>> graph={
        {0,4,2,0},
        {4,0,0,5},
        {2,0,0,3},
        {0,5,3,0}
    };

    dijkstra(graph,0);

    return 0;
}
```

# 19. Advantages

- Finds the shortest path efficiently.
- Works well for graphs with non-negative weights.
- Can compute shortest paths to **all vertices** from a single source.
- Widely used in real-world routing applications.

---

# 20. Limitations

- Does **not** work correctly with negative edge weights.
- Cannot detect negative weight cycles.
- Requires more memory than simple BFS due to the priority queue and distance array.

---

# 21. Common Mistakes

- Applying Dijkstra's Algorithm to graphs with negative edge weights.
- Forgetting to initialize distances to infinity.
- Not performing edge relaxation correctly.
- Failing to ignore outdated entries in the priority queue.
- Confusing **shortest path** with **minimum spanning tree**.

---

# 22. Best Practices

- Use an adjacency list with a priority queue for large sparse graphs.
- Always verify that edge weights are non-negative before choosing Dijkstra's Algorithm.
- Keep a parent array if the actual shortest path (not just the distance) must be reconstructed.
- Dry-run the algorithm using a distance table to understand relaxation.

# 26. Summary

- **Dijkstra's Algorithm** solves the **Single Source Shortest Path (SSSP)** problem for graphs with **non-negative edge weights**.
- The algorithm repeatedly selects the **unvisited vertex with the smallest known distance** and updates neighboring distances using **edge relaxation**.
- A **Priority Queue (Min Heap)** significantly improves efficiency, resulting in a time complexity of **O((V + E) log V)** with an adjacency list.
- Dijkstra's Algorithm is fundamentally different from **Minimum Spanning Tree** algorithms such as Prim's and Kruskal's because it minimizes the distance from a source rather than the total weight of the network.
- For graphs with **negative edge weights**, Dijkstra's Algorithm is not suitable; algorithms such as **Bellman-Ford** should be used instead.
