# Unit 5: Exploring Graphs

## Topic 5.4 — Breadth First Search (BFS)

## 1. Introduction

**Breadth First Search (BFS)** is a graph traversal algorithm that visits vertices **level by level**.

Unlike DFS, which goes as deep as possible before backtracking, BFS first visits all immediate neighbors of a vertex and then moves to the next level.

### Simple idea

```text
Start
  ↓
Visit all neighbors
  ↓
Visit neighbors of those vertices
  ↓
Continue level by level
```

BFS uses a **Queue** data structure.

A queue follows:

```text
FIFO = First In, First Out
```

---

# 2. Example

Consider the following graph:

```text
        0
       / \
      1   2
     / \
    3   4
```

Starting from vertex `0`, BFS visits:

```text
0 → 1 → 2 → 3 → 4
```

The traversal occurs level by level:

```text
Level 0:        0

Level 1:      1   2

Level 2:      3   4
```

Therefore:

```text
BFS = 0 1 2 3 4
```

---

# 3. BFS vs DFS

The main difference is how they explore the graph.

### DFS

```text
0 → 1 → 3 → 4 → 2
```

It explores deeply first.

### BFS

```text
0 → 1 → 2 → 3 → 4
```

It explores level by level.

| Feature                           | BFS                  | DFS                |
| --------------------------------- | -------------------- | ------------------ |
| Full form                         | Breadth First Search | Depth First Search |
| Principle                         | Level by level       | Depth first        |
| Main data structure               | Queue                | Stack / Recursion  |
| Order                             | Breadth-wise         | Depth-wise         |
| Shortest path in unweighted graph | Yes                  | Not guaranteed     |
| Time with adjacency list          | O(V + E)             | O(V + E)           |

---

# 4. Why Does BFS Use a Queue?

Suppose we start from `0`:

```text
        0
       / \
      1   2
     / \
    3   4
```

Initially:

```text
Queue: [0]
```

Remove `0` and visit it.

Add its neighbors:

```text
Queue: [1, 2]
```

Remove `1`.

```text
Queue: [2, 3, 4]
```

Remove `2`.

```text
Queue: [3, 4]
```

Remove `3`.

```text
Queue: [4]
```

Remove `4`.

```text
Queue: []
```

Traversal:

```text
0 1 2 3 4
```

The queue ensures that vertices are processed in the order in which they were discovered.

---

# 5. BFS Algorithm

### Algorithm

```text
BFS(G, start)

1. Create a visited array.
2. Create an empty queue.
3. Mark start as visited.
4. Insert start into the queue.

5. While queue is not empty:
      a. Remove a vertex from the queue.
      b. Process the vertex.
      c. For every adjacent vertex:
             If it is not visited:
                 Mark it visited.
                 Insert it into the queue.
```

### Important

A vertex should be marked as visited **when it is inserted into the queue**, not when it is removed.

This prevents the same vertex from being inserted multiple times.

# 7. BFS and Shortest Path

One of the most important applications of BFS is finding the **shortest path in an unweighted graph**.

Consider:

```text
        A
       / \
      B   C
      |   |
      D   E
       \ /
        F
```

From `A`:

```text
A → B
A → C
```

These vertices are at distance `1`.

Then:

```text
A → B → D
A → C → E
```

These are at distance `2`.

Then:

```text
A → B → D → F
```

has distance `3`.

BFS explores vertices according to their distance from the starting vertex.

Therefore, when BFS first reaches a vertex in an **unweighted graph**, it has found a shortest path to that vertex.

---

# 8. BFS for Shortest Distance

We can maintain a `distance[]` array.

Example:

```text
distance[0] = 0
```

When visiting an unvisited neighbor:

```text
distance[neighbor] = distance[current] + 1
```

For example:

```text
0 → 1 → 3
```

Distances:

```text
distance[0] = 0
distance[1] = 1
distance[3] = 2
```

# 9. BFS Implementation in Java

```java
import java.util.*;

public class BFSExample {

    static void bfs(
            ArrayList<ArrayList<Integer>> graph,
            int start) {

        boolean[] visited = new boolean[graph.size()];

        Queue<Integer> queue = new LinkedList<>();

        // Mark starting vertex as visited
        visited[start] = true;

        // Add starting vertex
        queue.add(start);

        while (!queue.isEmpty()) {

            // Remove vertex from queue
            int current = queue.poll();

            // Process vertex
            System.out.print(current + " ");

            // Visit all adjacent vertices
            for (int neighbor : graph.get(current)) {

                if (!visited[neighbor]) {

                    visited[neighbor] = true;

                    queue.add(neighbor);
                }
            }
        }
    }

    public static void main(String[] args) {

        int vertices = 6;

        ArrayList<ArrayList<Integer>> graph =
                new ArrayList<>();

        for (int i = 0; i < vertices; i++) {
            graph.add(new ArrayList<>());
        }

        // Undirected graph
        graph.get(0).add(1);
        graph.get(1).add(0);

        graph.get(0).add(2);
        graph.get(2).add(0);

        graph.get(1).add(3);
        graph.get(3).add(1);

        graph.get(1).add(4);
        graph.get(4).add(1);

        graph.get(2).add(5);
        graph.get(5).add(2);

        graph.get(4).add(5);
        graph.get(5).add(4);

        System.out.print("BFS Traversal: ");

        bfs(graph, 0);
    }
}
```

### Output

```text
BFS Traversal: 0 1 2 3 4 5
```

# 10. BFS Implementation in C++

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

void bfs(
    vector<vector<int>>& graph,
    int start) {

    int vertices = graph.size();

    vector<bool> visited(vertices, false);

    queue<int> q;

    // Mark starting vertex
    visited[start] = true;

    // Add starting vertex
    q.push(start);

    while (!q.empty()) {

        // Remove vertex from queue
        int current = q.front();
        q.pop();

        // Process vertex
        cout << current << " ";

        // Visit neighbors
        for (int neighbor : graph[current]) {

            if (!visited[neighbor]) {

                visited[neighbor] = true;

                q.push(neighbor);
            }
        }
    }
}

int main() {

    int vertices = 6;

    vector<vector<int>> graph(vertices);

    // Undirected graph
    graph[0].push_back(1);
    graph[1].push_back(0);

    graph[0].push_back(2);
    graph[2].push_back(0);

    graph[1].push_back(3);
    graph[3].push_back(1);

    graph[1].push_back(4);
    graph[4].push_back(1);

    graph[2].push_back(5);
    graph[5].push_back(2);

    graph[4].push_back(5);
    graph[5].push_back(4);

    cout << "BFS Traversal: ";

    bfs(graph, 0);

    return 0;
}
```

### Output

```text
BFS Traversal: 0 1 2 3 4 5
```

# 11. BFS for Disconnected Graph

Consider:

```text
0 ----- 1       2 ----- 3
```

There are two connected components.

If BFS starts from `0`:

```text
BFS: 0 1
```

Vertices `2` and `3` are not visited.

To traverse the complete graph:

```text
for each vertex:
    if vertex is not visited:
        BFS(vertex)
```

This performs BFS on every disconnected component.

---

# 12. Time and Space Complexity

Using an adjacency list:

### Time Complexity

```text
O(V + E)
```

where:

- `V` = number of vertices
- `E` = number of edges

Each vertex is processed once and each edge is examined during traversal.

### Auxiliary Space

```text
O(V)
```

for:

- `visited[]`
- queue

The adjacency list itself requires:

```text
O(V + E)
```

space.

# 13. Applications of BFS

BFS is commonly used for:

1. Graph traversal
2. Shortest path in an unweighted graph
3. Finding connected components
4. Level-order exploration
5. Finding the minimum number of edges between vertices
6. Exploring states in games or state-space problems

---

# 14. Important Limitation

BFS finds the shortest path based on the **number of edges** in an unweighted graph.

It should not be directly used as a general shortest-path algorithm for weighted graphs.

For example:

```text
A --1--> B
 \       |
  10     1
   \     |
    ---->C
```

BFS may prefer a path based on fewer edges, but the path with fewer edges is not necessarily the path with the lowest total weight.

For weighted shortest-path problems, algorithms such as **Dijkstra's algorithm** are used when its conditions are satisfied.

# 15. BFS vs DFS — Important Exam Question

| Parameter                         | BFS                   | DFS                                             |
| --------------------------------- | --------------------- | ----------------------------------------------- |
| Full form                         | Breadth First Search  | Depth First Search                              |
| Exploration                       | Level by level        | Depth first                                     |
| Data structure                    | Queue                 | Stack / Recursion                               |
| Principle                         | FIFO                  | LIFO                                            |
| Shortest path in unweighted graph | Yes                   | Not guaranteed                                  |
| Time complexity                   | O(V + E)              | O(V + E)                                        |
| Space                             | O(V) auxiliary        | O(V) auxiliary                                  |
| Common use                        | Shortest path, levels | Backtracking, cycle detection, topological sort |

### Easy way to remember

```text
BFS → Queue → Level by Level
DFS → Stack → Go Deep
```

# 18. Quick Revision

```text
BFS
 │
 ├── Start vertex
 │
 ├── Mark visited
 │
 ├── Insert into Queue
 │
 ├── Remove front vertex
 │
 ├── Process vertex
 │
 ├── Add unvisited neighbors
 │
 └── Repeat until Queue is empty
```

### Key Points

- **BFS = Breadth First Search**
- Uses a **Queue**
- Follows **FIFO**
- Visits vertices **level by level**
- Uses a `visited[]` array
- Time complexity using adjacency list: **O(V + E)**
- Can find shortest paths in **unweighted graphs**
- Works with both directed and undirected graphs.
- BFS is different from DFS mainly in its traversal strategy and underlying data structure.
