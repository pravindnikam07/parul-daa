# Unit 7: String Matching & NP Completeness

## Topic 7.4 — Knuth-Morris-Pratt (KMP) Algorithm

## 1. Introduction

The **Knuth-Morris-Pratt (KMP) algorithm** is an efficient string-matching algorithm.

Unlike the Naive algorithm, KMP avoids repeating comparisons that have already been performed.

The main idea is to preprocess the pattern and construct an array called the:

> **LPS (Longest Proper Prefix which is also a Suffix) array**

KMP uses the LPS array to decide **how far the pattern should move after a mismatch**.

---

# 2. Why KMP Is Needed

Consider:

```text
Text    = "ABABABABC"
Pattern = "ABABC"
```

The Naive algorithm may repeatedly compare the same `A` and `B` characters.

KMP recognizes that part of the pattern has already matched and uses that information instead of starting from the beginning.

```text
Naive:
Mismatch
   ↓
Shift by one
   ↓
Start again

KMP:
Mismatch
   ↓
Use LPS
   ↓
Shift intelligently
   ↓
Continue matching
```

---

# 3. Prefix and Suffix

To understand LPS, first understand **prefix** and **suffix**.

Consider:

```text
Pattern = "ABABC"
```

### Prefix

A prefix is a substring that starts from the beginning.

Examples:

```text
A
AB
ABA
ABAB
```

### Suffix

A suffix is a substring that ends at the end.

Examples:

```text
C
BC
ABC
BABC
```

---

# 4. Proper Prefix

A **proper prefix** cannot be the complete string itself.

For:

```text
ABAB
```

Proper prefixes are:

```text
A
AB
ABA
```

The complete string:

```text
ABAB
```

is not considered a proper prefix.

---

# 5. LPS Meaning

LPS stands for:

> **Longest Proper Prefix which is also a Suffix**

Consider:

```text
Pattern = "ABAB"
```

Prefixes:

```text
A
AB
ABA
```

Suffixes:

```text
B
AB
BAB
```

Common prefix and suffix:

```text
AB
```

Therefore:

$$
LPS("ABAB")=2
$$

---

Consider:

| ----: | --------- | ------------------------- | --: |

|     2 | A         | A                         |   1 |

# 8. How KMP Uses LPS

Suppose:

```text
Pattern = ABABC
```

and we have already matched:

```text
ABAB
```

Then a mismatch occurs.

Naive matching might restart from:

```text
A
```

KMP checks the LPS value.

For:

```text
ABAB
```

we have:

```text
LPS = 2
```

This means:

```text
AB
```

is both:

- a prefix of the pattern
- a suffix of the already matched portion

Therefore, KMP can continue from:

```text
Pattern index = 2
```

instead of starting from index `0`.

---

# 9. KMP Matching Process

```text
Text + Pattern
       ↓
Build LPS array
       ↓
Compare characters
       ↓
Match?
 /       \
Yes       No
 |         |
Move both  Use LPS
indices    |
 |         ↓
 |       Shift pattern
 ↓
Continue
```

---

# 10. LPS Construction

The LPS array is constructed **only from the pattern**.

Algorithm:

```text
LPS[0] = 0

length = 0
i = 1

while i < m:

    if pattern[i] == pattern[length]:

        length++
        LPS[i] = length
        i++

    else:

        if length != 0:
            length = LPS[length - 1]

        else:
            LPS[i] = 0
            i++
```

This preprocessing takes:

$$
\boxed{O(m)}
$$

time.

---

# 11. Java — Building LPS

```java id="kmpjava1"
static int[] buildLPS(String pattern) {

    int m = pattern.length();

    int[] lps = new int[m];

    int length = 0;
    int i = 1;

    while (i < m) {

        if (pattern.charAt(i) ==
            pattern.charAt(length)) {

            length++;
            lps[i] = length;
            i++;
        }
        else {

            if (length != 0) {

                length = lps[length - 1];

            }
            else {

                lps[i] = 0;
                i++;
            }
        }
    }

    return lps;
}
```

# 13. Complete KMP Algorithm

## Java

```java id="kmpjava2"
public class KMP {

    static int[] buildLPS(String pattern) {

        int m = pattern.length();

        int[] lps = new int[m];

        int length = 0;
        int i = 1;

        while (i < m) {

            if (pattern.charAt(i) ==
                pattern.charAt(length)) {

                length++;
                lps[i] = length;
                i++;
            }
            else {

                if (length != 0) {
                    length = lps[length - 1];
                }
                else {
                    lps[i] = 0;
                    i++;
                }
            }
        }

        return lps;
    }

    static void search(String text, String pattern) {

        int n = text.length();
        int m = pattern.length();

        int[] lps = buildLPS(pattern);

        int i = 0;
        int j = 0;

        while (i < n) {

            if (text.charAt(i) ==
                pattern.charAt(j)) {

                i++;
                j++;

                if (j == m) {

                    System.out.println(
                        "Pattern found at index "
                        + (i - j)
                    );

                    j = lps[j - 1];
                }
            }
            else {

                if (j != 0) {
                    j = lps[j - 1];
                }
                else {
                    i++;
                }
            }
        }
    }

    public static void main(String[] args) {

        String text = "ABABDABACDABABCABAB";
        String pattern = "ABABCABAB";

        search(text, pattern);
    }
}
```

### Output

```text
Pattern found at index 10
```

```cpp id="kmpcpp2"
#include <vector>
#include <string>

using namespace std;

vector<int> buildLPS(string pattern) {

    int m = pattern.length();

    vector<int> lps(m, 0);

    int length = 0;
    int i = 1;

    while (i < m) {

        if (pattern[i] == pattern[length]) {

            length++;
            lps[i] = length;
            i++;
        }
        else {

            if (length != 0) {

                length = lps[length - 1];

            }
            else {

                lps[i] = 0;
                i++;
            }
        }
    }

    return lps;
}

void searchPattern(string text, string pattern) {

    int n = text.length();
    int m = pattern.length();

    vector<int> lps = buildLPS(pattern);

    int i = 0;
    int j = 0;

    while (i < n) {

        if (text[i] == pattern[j]) {

            i++;
            j++;

            if (j == m) {

                cout << "Pattern found at index "
                     << i - j << endl;

                j = lps[j - 1];
            }
        }
        else {

            if (j != 0) {

                j = lps[j - 1];

            }
            else {

                i++;
            }
        }
    }
}

int main() {

    string text =
        "ABABDABACDABABCABAB";

    string pattern =
        "ABABCABAB";

    searchPattern(text, pattern);

    return 0;
}
```

```text

```

# 16. KMP Matching Dry Run

Consider:

```text
Text:
ABABDABACDABABCABAB

Pattern:
ABABCABAB
```

After some comparisons, KMP reaches a mismatch after matching:

```text
ABAB
```

The LPS value for the matched portion is:

```text
2
```

Therefore, instead of:

```text
j = 0
```

KMP does:

```text
j = 2
```

The already-known prefix:

```text
AB
```

can be reused.

This is the central idea of KMP.

---

# 17. Why KMP Is Efficient

The key rule is:

### When characters match

```text
i++
j++
```

### When mismatch occurs and `j > 0`

```text
j = LPS[j - 1]
```

The text index `i` does **not** move backward.

This is why KMP avoids repeated comparisons.

---

# 18. Complexity

### LPS Construction

$$
\boxed{O(m)}
$$

### Pattern Matching

$$
\boxed{O(n)}
$$

Therefore:

$$
\boxed{O(n+m)}
$$

overall.

### Space Complexity

The LPS array requires:

$$
\boxed{O(m)}
$$

space.

# 19. Naive vs Rabin-Karp vs KMP

| Feature          | Naive             | Rabin-Karp       | KMP       |
| ---------------- | ----------------- | ---------------- | --------- |
| Main idea        | Direct comparison | Hashing          | LPS       |
| Preprocessing    | No                | Hash preparation | LPS array |
| Expected/typical | `O(nm)`           | `O(n+m)`         | `O(n+m)`  |
| Worst case       | `O(nm)`           | `O(nm)`          | `O(n+m)`  |
| Extra space      | `O(1)`            | `O(1)`           | `O(m)`    |
| Collision issue  | No                | Yes              | No        |

# 20. Important Difference: LPS Is Not "Matched Characters"

For:

```text
Pattern = ABABC
```

the LPS array is:

```text
0 0 1 2 0
```

It does **not** simply indicate how many characters have matched.

It indicates:

> The length of the longest proper prefix of the pattern that is also a suffix ending at that position.

---

# 21. Common Mistakes

### Mistake 1 — Using `LPS[j]` instead of `LPS[j-1]`

After a mismatch:

```java
j = lps[j - 1];
```

is the correct update when `j > 0`.

---

### Mistake 2 — Moving the text index backward

KMP does not move `i` backward.

```text
i only moves forward
```

---

### Mistake 3 — Including the complete string as a proper prefix

For:

```text
ABAB
```

`ABAB` itself is not a proper prefix.

---

### Mistake 4 — Forgetting overlapping matches

For:

```text
Text    = "AAAAA"
Pattern = "AAA"
```

matches occur at:

```text
0
1
2
```

After finding a match, KMP can continue with:

```text
j = lps[j - 1]
```

rather than resetting `j` to zero.

# 24. Quick Revision

### KMP Process

```text
Pattern
   ↓
Build LPS
   ↓
Compare Text & Pattern
   ↓
Mismatch?
 /       \
No       Yes
 |         |
Continue   j = LPS[j-1]
             ↓
          Continue
```

### Key Formula

When mismatch occurs and:

$$
j>0
$$

then:

$$
\boxed{j=LPS[j-1]}
$$

### Complexity

$$
\boxed{\text{LPS Construction: }O(m)}
$$

$$
\boxed{\text{Searching: }O(n)}
$$

$$
\boxed{\text{Overall: }O(n+m)}
$$

$$
\boxed{\text{Space: }O(m)}
$$

### Core Idea

> **KMP avoids rechecking characters by using information about prefixes and suffixes stored in the LPS array.**
