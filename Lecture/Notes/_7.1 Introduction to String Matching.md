# Unit 7: String Matching & NP Completeness

## Topic 7.1 — Introduction to String Matching

## 1. Introduction

**String Matching** is the process of finding the occurrence of a **pattern** inside a larger **text**.

### Example

```text
Text    = "ABABCABAB"
Pattern = "ABAB"
```

The pattern occurs starting at index `0` and again at index `5`.

```text
ABABCABAB
^^^^
     ^^^^
```

String matching is an important problem in:

- Text searching
- Search engines
- DNA sequence analysis
- Plagiarism detection
- Information retrieval
- Pattern recognition

The syllabus covers four string-matching techniques:

1. **Naive String Matching**
2. **Rabin-Karp Algorithm**
3. **Knuth-Morris-Pratt (KMP) Algorithm**
4. **String Matching using Finite Automata**

# 5. String Matching Problem

Given:

```text
Text T of length n
Pattern P of length m
```

find all positions `i` such that:

$$
T[i \ldots i+m-1] = P[0 \ldots m-1]
$$

In simple words:

> Find every position in the text where the complete pattern occurs.

---

# 6. Why String Matching Algorithms Are Needed

A simple approach can compare the pattern against the text at every possible position.

For a large text, this may require many comparisons.

For example:

```text
Text:
A A A A A A A A A A A B

Pattern:
A A A A A B
```

A simple algorithm may perform many repeated comparisons.

More efficient algorithms try to reduce unnecessary comparisons.

---

# 7. General String Matching Process

```text
             Text
              ↓
       Select text position
              ↓
      Compare with pattern
              ↓
          Match?
        /         \
      Yes          No
       ↓            ↓
  Pattern found   Shift pattern
       ↓            ↓
  Continue search
```

Different algorithms differ mainly in **how they compare and shift the pattern**.

---

# 8. Naive String Matching

The **Naive String Matching Algorithm** is the simplest string-matching technique.

It checks the pattern at **every possible position** in the text.

For every position:

```text
Compare:
Text substring
     with
Pattern
```

If all characters match, an occurrence is found.

---

# 9. Naive String Matching Example

Consider:

```text
Text    = "ABABC"
Pattern = "ABC"
```

### Shift 0

```text
Text:
A B A B C
| | |
Pattern:
A B C
```

Comparison:

```text
A = A ✓
B = B ✓
A ≠ C ✗
```

No match.

---

### Shift 1

```text
A B A B C
  A B C
```

```text
B ≠ A
```

No match.

---

### Shift 2

```text
A B A B C
    A B C
```

```text
A = A ✓
B = B ✓
C = C ✓
```

Match found at index `2`.

---

# 10. Naive Algorithm

```text
NaiveStringMatch(T, P)

n = length of T
m = length of P

for i = 0 to n - m:

    j = 0

    while j < m
          and T[i + j] == P[j]:

        j++

    if j == m:
        report match at i
```

---

# 11. Java Implementation

```java
public class NaiveStringMatching {

    static void search(String text, String pattern) {

        int n = text.length();
        int m = pattern.length();

        for (int i = 0; i <= n - m; i++) {

            int j = 0;

            while (j < m &&
                   text.charAt(i + j) ==
                   pattern.charAt(j)) {

                j++;
            }

            if (j == m) {
                System.out.println(
                    "Pattern found at index " + i
                );
            }
        }
    }

    public static void main(String[] args) {

        String text = "ABABCABAB";
        String pattern = "ABAB";

        search(text, pattern);
    }
}
```

### Output

```text
Pattern found at index 0
Pattern found at index 5
```

# 12. C++ Implementation

```cpp
#include <iostream>
#include <string>
using namespace std;

void searchPattern(string text, string pattern) {

    int n = text.length();
    int m = pattern.length();

    for (int i = 0; i <= n - m; i++) {

        int j = 0;

        while (j < m &&
               text[i + j] == pattern[j]) {

            j++;
        }

        if (j == m) {
            cout << "Pattern found at index "
                 << i << endl;
        }
    }
}

int main() {

    string text = "ABABCABAB";
    string pattern = "ABAB";

    searchPattern(text, pattern);

    return 0;
}
```

### Output

```text
Pattern found at index 0
Pattern found at index 5
```

# 14. Complexity of Naive String Matching

There are:

$$
n-m+1
$$

possible alignments.

At each alignment, up to `m` characters may be compared.

Therefore, the worst-case time complexity is:

$$
\boxed{O((n-m+1)m)}
$$

Usually expressed as:

$$
\boxed{O(nm)}
$$

### Best Case

If a mismatch occurs immediately at each position:

$$
\boxed{O(n)}
$$

### Space Complexity

The algorithm uses a constant amount of extra space:

$$
\boxed{O(1)}
$$

excluding the input strings.

---

# 15. Why Naive Matching Can Be Slow

Consider:

```text
Text:
AAAAAAAAAAAAAAAAAB

Pattern:
AAAAAAB
```

The algorithm may repeatedly compare several `A`s before discovering a mismatch.

After the mismatch, it shifts only one position and starts comparing again.

This repeated work motivates more advanced algorithms.

# 16. Overview of String Matching Algorithms

| Algorithm       | Main Idea                                 | Typical Strength                  |
| --------------- | ----------------------------------------- | --------------------------------- |
| Naive           | Compare pattern at every position         | Simple                            |
| Rabin-Karp      | Compare hash values                       | Useful for multiple patterns      |
| KMP             | Use previously matched prefix information | Avoids repeated comparisons       |
| Finite Automata | Use precomputed state transitions         | Fast matching after preprocessing |

The remaining topics in this unit build on the basic string-matching problem introduced here.

# 17. Important Difference: Search vs String Matching

String matching specifically focuses on finding a **pattern within a text**.

For example:

```text
Text    = "Data Structures and Algorithms"
Pattern = "Algorithms"
```

The task is to determine where `"Algorithms"` occurs.

It is not necessary to sort the text or rearrange its characters.

# 19. Important Edge Cases

When implementing string matching, consider:

### Pattern longer than text

```text
Text    = "ABC"
Pattern = "ABCDE"
```

No match is possible.

### Empty pattern

The behavior should be defined by the implementation or problem specification.

### Pattern equal to text

```text
Text    = "ABC"
Pattern = "ABC"
```

Match at index `0`.

### Repeated characters

```text
Text    = "AAAAA"
Pattern = "AA"
```

Multiple overlapping matches are possible.
