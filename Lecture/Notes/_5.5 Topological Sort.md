# Unit 5: Exploring Graphs

## Topic 5.5 — Topological Sort

## 1. Introduction

**Topological Sorting** is a linear ordering of the vertices of a **directed graph** such that for every directed edge:

```text
u → v
```

vertex `u` appears **before** vertex `v` in the ordering.

### Important Condition

Topological sorting is possible only for a:

> **Directed Acyclic Graph (DAG)**

A DAG is a directed graph that contains **no cycle**.

---

# 2. Simple Example

Consider:

```text
A → B → D
↓
C → D
```

A valid topological ordering is:

```text
A B C D
```

Why?

```text
A → B    A comes before B
A → C    A comes before C
B → D    B comes before D
C → D    C comes before D
```

Another valid ordering can also exist:

```text
A C B D
```

Both are correct.

### Important

A graph can have **more than one valid topological ordering**.

# 6. Method 1 — Topological Sort Using DFS

Topological sorting can be performed using **Depth First Search**.

### Basic idea

During DFS:

1. Visit a vertex.
2. Visit all its unvisited neighbors.
3. After all neighbors are processed, place the vertex into a stack.
4. Continue until all vertices are processed.
5. Pop vertices from the stack to obtain the topological ordering.

The important idea is:

> **Insert a vertex into the stack after all of its outgoing neighbors have been processed.**

---

# 7. DFS Topological Sort Algorithm

```text
TopologicalSort(G)

1. Create visited[].
2. Create an empty stack.
3. For every vertex v:
      If v is not visited:
          DFS(v)

4. While stack is not empty:
      Pop and print the top vertex.
```

DFS:

```text
DFS(v)

1. Mark v as visited.
2. For every adjacent vertex u:
      If u is not visited:
          DFS(u)
3. Push v into stack.
```

# 8. Dry Run

Consider:

```text
5 → 0 → 1 → 4
 \
  → 2 → 3 → 4
```

Start DFS from `5`.

### DFS sequence

```text
5
 ↓
0
 ↓
1
 ↓
4
```

Vertex `4` has no outgoing edge.

Push:

```text
Stack: [4]
```

Backtrack to `1`.

```text
Stack: [4, 1]
```

Backtrack to `0`.

```text
Stack: [4, 1, 0]
```

Return to `5` and explore `2`.

```text
5 → 2 → 3
```

After processing `3`, its neighbor `4` is already visited.

Push:

```text
Stack: [4, 1, 0, 3]
```

Then:

```text
Stack: [4, 1, 0, 3, 2]
```

Finally:

```text
Stack: [4, 1, 0, 3, 2, 5]
```

Pop from the stack:

```text
5 2 3 0 1 4
```

This is a valid topological ordering.

# 9. Java Implementation — DFS Method

```java
import java.util.*;

public class TopologicalSortDFS {

    static void dfs(
            int vertex,
            ArrayList<ArrayList<Integer>> graph,
            boolean[] visited,
            Stack<Integer> stack) {

        visited[vertex] = true;

        for (int neighbor : graph.get(vertex)) {

            if (!visited[neighbor]) {
                dfs(neighbor, graph, visited, stack);
            }
        }

        // Add after processing all neighbors
        stack.push(vertex);
    }

    static void topologicalSort(
            ArrayList<ArrayList<Integer>> graph) {

        int vertices = graph.size();

        boolean[] visited = new boolean[vertices];

        Stack<Integer> stack = new Stack<>();

        for (int i = 0; i < vertices; i++) {

            if (!visited[i]) {
                dfs(i, graph, visited, stack);
            }
        }

        System.out.print("Topological Order: ");

        while (!stack.isEmpty()) {
            System.out.print(stack.pop() + " ");
        }
    }

    public static void main(String[] args) {

        int vertices = 6;

        ArrayList<ArrayList<Integer>> graph =
                new ArrayList<>();

        for (int i = 0; i < vertices; i++) {
            graph.add(new ArrayList<>());
        }

        graph.get(5).add(0);
        graph.get(5).add(2);
        graph.get(0).add(1);
        graph.get(2).add(3);
        graph.get(1).add(4);
        graph.get(3).add(4);

        topologicalSort(graph);
    }
}
```

### Possible Output

```text
Topological Order: 5 2 3 0 1 4
```

The exact valid ordering can vary depending on the adjacency-list order.

```cpp
#include <vector>

void dfs(
    int vertex,
    vector<vector<int>>& graph,
    vector<bool>& visited,
    stack<int>& st) {

    visited[vertex] = true;

    for (int neighbor : graph[vertex]) {

            dfs(neighbor, graph, visited, st);
        }

    // Add after processing all neighbors
    st.push(vertex);

    int vertices = graph.size();
```

# 11. Method 2 — Kahn's Algorithm

Another important method for topological sorting is **Kahn's Algorithm**.

It uses:

* **In-degree**
* **Queue**

### Main idea

1. Calculate the in-degree of every vertex.
2. Find all vertices with in-degree `0`.
3. Add them to a queue.
4. Remove a vertex from the queue.
5. Add it to the topological ordering.
6. Reduce the in-degree of its neighbors.
7. If a neighbor's in-degree becomes `0`, add it to the queue.
8. Continue until the queue is empty.

---

# 12. Kahn's Algorithm Example

Consider:

```text
5 → 0 → 1 → 4
 \
  → 2 → 3 → 4
```

Initial in-degrees:

| Vertex | In-degree |
| -----: | --------: |
|      0 |         1 |
|      1 |         1 |
|      2 |         1 |
|      3 |         1 |
|      4 |         2 |
|      5 |         0 |

Only vertex `5` has in-degree `0`.

```text
Queue: [5]
```

Remove `5`:

```text
Order: 5
```

Reduce in-degree of `0` and `2`:

```text
0 → 0
2 → 0
```

Add them:

```text
Queue: [0, 2]
```

Continue processing.

A valid result can be:

```text
5 0 2 1 3 4
```

---

# 13. Java — Kahn's Algorithm

```java
import java.util.*;

public class TopologicalSortKahn {

    static void topologicalSort(
            ArrayList<ArrayList<Integer>> graph) {

        int vertices = graph.size();

        int[] indegree = new int[vertices];

        // Calculate in-degree
        for (int i = 0; i < vertices; i++) {

            for (int neighbor : graph.get(i)) {
                indegree[neighbor]++;
            }
        }

        Queue<Integer> queue = new LinkedList<>();

        // Add vertices having in-degree 0
        for (int i = 0; i < vertices; i++) {

            if (indegree[i] == 0) {
                queue.add(i);
            }
        }

        int count = 0;

        System.out.print("Topological Order: ");

        while (!queue.isEmpty()) {

            int current = queue.poll();

            System.out.print(current + " ");

            count++;

            for (int neighbor : graph.get(current)) {

                indegree[neighbor]--;

                if (indegree[neighbor] == 0) {
                    queue.add(neighbor);
                }
            }
        }

        // Cycle detection
        if (count != vertices) {
            System.out.println("\nTopological sorting is not possible.");
            System.out.println("Graph contains a cycle.");
        }
    }

    public static void main(String[] args) {

        int vertices = 6;

        ArrayList<ArrayList<Integer>> graph =
                new ArrayList<>();

        for (int i = 0; i < vertices; i++) {
            graph.add(new ArrayList<>());
        }

        graph.get(5).add(0);
        graph.get(5).add(2);
        graph.get(0).add(1);
        graph.get(2).add(3);
        graph.get(1).add(4);
        graph.get(3).add(4);

        topologicalSort(graph);
    }
}
```

# 14. C++ — Kahn's Algorithm

```cpp
#include <iostream>
#include <vector>
#include <queue>
using namespace std;

void topologicalSort(vector<vector<int>>& graph) {

    int vertices = graph.size();

    vector<int> indegree(vertices, 0);

    // Calculate in-degree
    for (int i = 0; i < vertices; i++) {

        for (int neighbor : graph[i]) {
            indegree[neighbor]++;
        }
    }

    queue<int> q;

    // Add vertices with in-degree 0
    for (int i = 0; i < vertices; i++) {

        if (indegree[i] == 0) {
            q.push(i);

    int count = 0;

    cout << "Topological Order: ";

    while (!q.empty()) {

        int current = q.front();
        q.pop();

    if (count != vertices) {
        cout << "\nTopological sorting is not possible.";

}
```

# 15. Detecting a Cycle

Topological sorting is possible only when the graph is a **DAG**.

Consider:

```text
A → B
↑   |
|   ↓
D ← C
```

This contains the cycle:

```text
A → B → C → D → A
```

Therefore:

```text
Topological Sort = Not Possible
```

### Using Kahn's Algorithm

If the number of processed vertices is less than the total number of vertices:

```text
processed vertices < V
```

then the graph contains a cycle.

---

# 16. DFS vs Kahn's Algorithm

| Feature         | DFS Method                | Kahn's Algorithm  |
| --------------- | ------------------------- | ----------------- |
| Main technique  | DFS                       | BFS-like approach |
| Data structure  | Stack                     | Queue             |
| Uses            | DFS + visited             | In-degree         |
| Cycle detection | Requires additional state | `count != V`      |
| Time            | O(V + E)                  | O(V + E)          |
| Space           | O(V)                      | O(V)              |

# 17. Important Exam Points

### Topological sort is applicable to:

```text
Directed Acyclic Graph (DAG)
```

### It is not applicable to:

```text
Undirected graph
```

in the standard dependency-ordering sense.

### It is also not possible for:

```text
Directed graph containing a cycle
```

### Multiple answers can exist

For:

```text
A → C
B → C
```

both can be valid:

```text
A B C
```

and:

```text
B A C
```

# 18. Complexity

Using an adjacency list:

### DFS Method

```text
Time = O(V + E)
Space = O(V)
```

### Kahn's Algorithm

```text
Time = O(V + E)
Space = O(V)
```

where:

* `V` = number of vertices
* `E` = number of edges

```text
Topological Sort
       │

       ├── Must be Acyclic

       ├── Every edge u → v
       │       means
```

### Key Points

* Topological sorting gives a **dependency-respecting linear order**.
* It is applicable to a **DAG**.
* Every source vertex must appear before its dependent vertex.
* Two major methods:

  * **DFS + Stack**
  * **Kahn's Algorithm**
* Time complexity: **O(V + E)**.
* A DAG can have **multiple valid topological orderings**.
* A directed cycle makes topological sorting impossible.
