# 2. Motivation

Suppose two students submit two versions of an assignment:

```text
Version 1:
A B C D E F

Version 2:
A C D F
```

We want to find the longest sequence that appears in both while preserving the original order.

Here:

```text
A C D F
```

appears in both.

Therefore:

```text
LCS = ACDF
Length = 4
```

This is the **Longest Common Subsequence** problem.

---

# 3. What is a Subsequence?

A **subsequence** is obtained by deleting zero or more elements from a sequence **without changing the order of the remaining elements**.

Consider:

```text
S = ABCDE
```

Some subsequences are:

```text
A
B
AC
ACE
BCD
ABCDE
```

All are valid because the relative order is preserved.

---

# 4. What is NOT a Subsequence?

Consider:

```text
S = ABCDE
```

The following is not a subsequence:

```text
CA
```

Why?

Because in the original string:

```text
A comes before C
```

but in `CA`:

```text
C comes before A
```

The order has changed.

---

# 5. Subsequence vs Substring

This distinction is extremely important.

## Subsequence

Characters **do not have to be adjacent**.

Example:

```text
ABCDE
```

`ACE` is a subsequence.

---

## Substring

Characters must be **continuous/adjacent**.

Example:

```text
ABCDE
```

`BCD` is a substring.

But:

```text
ACE
```

is not a substring.

---

## Comparison

| Feature                      | Subsequence | Substring |
| ---------------------------- | ----------- | --------- |
| Characters must be adjacent? | No          | Yes       |
| Relative order preserved?    | Yes         | Yes       |
| Example from `ABCDE`         | `ACE`       | `BCD`     |
| LCS uses                     | Subsequence | —         |

---

# 6. Problem Definition

Given two sequences:

```text
X = x1 x2 ... xm
Y = y1 y2 ... yn
```

find the longest sequence that:

1. is a subsequence of `X`,
2. is a subsequence of `Y`,
3. has maximum possible length.

---

# 7. Example

Consider:

```text
X = ABCDGH
Y = AEDFHR
```

One common subsequence is:

```text
A D H
```

Another:

```text
A F
```

The longest common subsequence is:

```text
ADH
```

Therefore:

```text
LCS Length = 3
```

# 8. Real-World Applications

LCS is not just an academic problem.

It is used conceptually in:

### 1. File comparison

Finding common portions between two files.

### 2. Version control

Tools such as diff-style systems compare versions of files and identify inserted/deleted sections.

### 3. DNA sequence analysis

Comparing biological sequences.

Example:

```text
DNA 1: A C G T A
DNA 2: A G T A
```

### 4. Plagiarism / similarity analysis

Finding common ordered portions of text.

### 5. Text comparison

Comparing documents, messages, and revisions.

# 9. Why Dynamic Programming?

A brute-force approach would generate subsequences of the strings and compare them.

For a string of length `n`, there can be:

```text
2^n
```

subsequences.

This becomes extremely expensive.

LCS has:

### Overlapping Subproblems

The same prefix comparisons occur repeatedly.

### Optimal Substructure

The optimal solution can be constructed from optimal solutions of smaller prefixes.

Therefore, Dynamic Programming is suitable.

---

# 10. DP State

Let:

```text
dp[i][j]
```

represent:

> The length of the LCS between the first `i` characters of X and the first `j` characters of Y.

This definition should be written clearly before coding.

---

# 11. Base Case

If either string is empty:

```text
X = ""
Y = "ABC"
```

there is no common subsequence.

Therefore:

```text
dp[0][j] = 0
```

and:

```text
dp[i][0] = 0
```

for all valid `i` and `j`.

---

# 12. The Main Cases

There are two important cases.

---

## Case 1: Characters Match

Suppose:

```text
X[i-1] == Y[j-1]
```

Then that character can be part of the LCS.

Therefore:

```text
dp[i][j] = 1 + dp[i-1][j-1]
```

---

## Case 2: Characters Do Not Match

Suppose:

```text
X[i-1] != Y[j-1]
```

Then at least one of the current characters must be excluded.

We consider both possibilities:

```text
dp[i-1][j]
```

and:

```text
dp[i][j-1]
```

Therefore:

```text
dp[i][j] = max(dp[i-1][j], dp[i][j-1])
```

---

# 13. LCS Recurrence

The complete recurrence is:

```text
if X[i-1] == Y[j-1]

    dp[i][j] =
        1 + dp[i-1][j-1]

else

    dp[i][j] =
        max(
            dp[i-1][j],
            dp[i][j-1]
        )
```

Base case:

```text
dp[i][0] = 0
dp[0][j] = 0
```

---

# 14. Why Do We Use `i-1` and `j-1`?

Students frequently make this mistake.

Our DP table has:

```text
dp[0][...]
```

representing an empty prefix.

Therefore:

```text
dp[i][j]
```

corresponds to:

```text
X[i-1]
Y[j-1]
```

because Java/C++ strings use zero-based indexing.

---

# 15. Complete Dry Run

Consider:

```text
X = ABCD
Y = ACBD
```

We construct the DP table.

Rows represent `X`.

Columns represent `Y`.

```text
      "" A C B D
""     0 0 0 0 0
A      0
B      0
C      0
D      0
```

---

## Step 1: Compare A and A

They match.

```text
dp[1][1]
=
1 + dp[0][0]
=
1
```

---

## Step 2: Compare A and C

They don't match.

```text
max(
    dp[0][2],
    dp[1][1]
)
```

```text
max(0,1) = 1
```

---

## Step 3: Compare A and B

No match:

```text
dp[1][3] = 1
```

---

## Step 4: Compare A and D

No match:

```text
dp[1][4] = 1
```

---

# 16. Continue the Table

Final table:

| X \ Y | `""` |     A |     C |     B |     D |
| ----- | ---: | ----: | ----: | ----: | ----: |
| `""`  |    0 |     0 |     0 |     0 |     0 |
| A     |    0 | **1** |     1 |     1 |     1 |
| B     |    0 |     1 |     1 | **2** |     2 |
| C     |    0 |     1 | **2** |     2 |     2 |
| D     |    0 |     1 |     2 |     2 | **3** |

Therefore:

```text
LCS Length = dp[4][4] = 3
```

---

# 17. Find the Actual LCS

The DP table gives us:

```text
Length = 3
```

But suppose we want:

```text
LCS = ABD
```

We need to trace the table backward.

Start from:

```text
dp[4][4]
```

---

## Step 1

Characters:

```text
X[3] = D
Y[3] = D
```

They match.

Therefore:

```text
D
```

is part of the LCS.

Move diagonally:

```text
dp[3][3]
```

---

## Step 2

Now:

```text
X[2] = C
Y[2] = B
```

They don't match.

Compare:

```text
dp[2][3] = 2
dp[3][2] = 2
```

Both are possible paths.

If we choose one path, we can obtain one valid LCS.

---

## Important Point

When multiple DP cells have the same value, **multiple valid LCS strings may exist**.

The LCS is not necessarily unique.

---

# 18. LCS Backtracking Rule

Start at:

```text
i = m
j = n
```

### If characters match:

```text
X[i-1] == Y[j-1]
```

Then:

```text
Add character
i--
j--
```

### If they don't match:

If:

```text
dp[i-1][j] > dp[i][j-1]
```

move:

```text
i--
```

Otherwise:

```text
j--
```

Continue until:

```text
i == 0
```

or:

```text
j == 0
```

Since characters are collected from the end toward the beginning, reverse the result at the end.

---

# 19. Java Implementation — LCS Length

```java
public class LCS {

    static int lcs(String X, String Y) {

        int m = X.length();
        int n = Y.length();

        int[][] dp = new int[m + 1][n + 1];

        for (int i = 1; i <= m; i++) {

            for (int j = 1; j <= n; j++) {

                if (X.charAt(i - 1)
                        == Y.charAt(j - 1)) {

                    dp[i][j] =
                        1 + dp[i - 1][j - 1];

                } else {

                    dp[i][j] =
                        Math.max(
                            dp[i - 1][j],
                            dp[i][j - 1]
                        );
                }
            }
        }

        return dp[m][n];
    }

    public static void main(String[] args) {

        String X = "ABCD";
        String Y = "ACBD";

        System.out.println(
            lcs(X, Y)
        );
    }
}
```

Output:

```text
3
```

# 21. Java — Print Actual LCS

```java
public class PrintLCS {

    static String findLCS(String X, String Y) {

        int m = X.length();
        int n = Y.length();

        int[][] dp = new int[m + 1][n + 1];

        // Build DP table
        for (int i = 1; i <= m; i++) {

            for (int j = 1; j <= n; j++) {

                if (X.charAt(i - 1)
                        == Y.charAt(j - 1)) {

                    dp[i][j] =
                        1 + dp[i - 1][j - 1];

                } else {

                    dp[i][j] =
                        Math.max(
                            dp[i - 1][j],
                            dp[i][j - 1]
                        );
                }
            }
        }

        StringBuilder result =
            new StringBuilder();

        int i = m;
        int j = n;

        while (i > 0 && j > 0) {

            if (X.charAt(i - 1)
                    == Y.charAt(j - 1)) {

                result.append(X.charAt(i - 1));

                i--;
                j--;

            } else if (dp[i - 1][j]
                    > dp[i][j - 1]) {

                i--;

            } else {

                j--;
            }
        }

        return result.reverse().toString();
    }

    public static void main(String[] args) {

        String X = "ABCBDAB";
        String Y = "BDCABA";

        String answer =
            findLCS(X, Y);

        System.out.println(
            "LCS = " + answer
        );

        System.out.println(
            "Length = " + answer.length()
        );
    }
}
```

One possible output:

```text
LCS = BCBA
Length = 4
```

Another valid LCS can exist, such as:

```text
BDAB
```

This is normal.

# 22. C++ — Print Actual LCS

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

string findLCS(string X, string Y) {

    int m = X.length();
    int n = Y.length();

    vector<vector<int>> dp(
        m + 1,
        vector<int>(n + 1, 0)
    );

    for (int i = 1; i <= m; i++) {

        for (int j = 1; j <= n; j++) {

            if (X[i - 1] == Y[j - 1]) {

                dp[i][j] =
                    1 + dp[i - 1][j - 1];

            } else {

                dp[i][j] =
                    max(
                        dp[i - 1][j],
                        dp[i][j - 1]
                    );
            }
        }
    }

    string result;

    int i = m;
    int j = n;

    while (i > 0 && j > 0) {

        if (X[i - 1] == Y[j - 1]) {

            result += X[i - 1];

            i--;
            j--;

        } else if (dp[i - 1][j]
                   > dp[i][j - 1]) {

            i--;

        } else {

            j--;
        }
    }

    reverse(result.begin(), result.end());

    return result;
}

int main() {

    string X = "ABCBDAB";
    string Y = "BDCABA";

    string answer =
        findLCS(X, Y);

    cout << "LCS = " << answer << endl;
    cout << "Length = "
         << answer.length();

    return 0;
}
```

# 23. Recursive LCS

Before Dynamic Programming, we can define the recursive solution.

```text
LCS(i, j)

if i == 0 or j == 0:
    return 0

if X[i-1] == Y[j-1]:

    return 1 + LCS(i-1, j-1)

else:

    return max(
        LCS(i-1, j),
        LCS(i, j-1)
    )
```

This directly follows the recurrence.

---

# 24. Why Simple Recursion Is Inefficient

Consider:

```text
X = ABCDE
Y = ACDFE
```

When characters don't match, recursion branches:

```text
LCS(i-1,j)
       +
LCS(i,j-1)
```

The same states can be calculated repeatedly.

For example:

```text
LCS(3,3)
```

may be reached through multiple paths.

Therefore, the naive recursive solution has exponential time in the worst case.

Dynamic Programming stores these results.

---

# 25. Memoization

We can store:

```text
dp[i][j]
```

after calculating it once.

Then:

```text
if dp[i][j] != -1
    return dp[i][j]
```

This avoids repeated computation.

---

# 26. Java Memoization

```java
import java.util.Arrays;

public class LCSMemo {

    static int[][] dp;

    static int solve(
        String X,
        String Y,
        int i,
        int j
    ) {

        if (i == 0 || j == 0)
            return 0;

        if (dp[i][j] != -1)
            return dp[i][j];

        if (X.charAt(i - 1)
                == Y.charAt(j - 1)) {

            return dp[i][j] =
                1 + solve(
                    X, Y,
                    i - 1,
                    j - 1
                );

        }

        return dp[i][j] =
            Math.max(
                solve(X, Y, i - 1, j),
                solve(X, Y, i, j - 1)
            );
    }

    public static void main(String[] args) {

        String X = "ABCBDAB";
        String Y = "BDCABA";

        dp = new int[
            X.length() + 1
        ][
            Y.length() + 1
        ];

        for (int[] row : dp)
            Arrays.fill(row, -1);

        System.out.println(
            solve(
                X,
                Y,
                X.length(),
                Y.length()
            )
        );
    }
}
```

# 27. Complexity Analysis

Let:

```text
m = length of X
n = length of Y
```

Number of DP states:

```text
O(m × n)
```

Each state takes:

```text
O(1)
```

work.

Therefore:

### Time

```text
O(m × n)
```

### Space

```text
O(m × n)
```

for the standard DP table.

---

# 28. Space Optimization

If we only need the **LCS length**, not the actual LCS, we don't necessarily need the entire 2D table.

We can reduce space to:

```text
O(min(m,n))
```

using two rows or one row.

However:

> If we need to reconstruct the actual LCS using the standard backtracking method, keeping the 2D table is the simplest teaching and implementation approach.

# 29. LCS vs Longest Common Substring

This is one of the most common exam questions.

| LCS                             | Longest Common Substring          |
| ------------------------------- | --------------------------------- |
| Characters need not be adjacent | Characters must be adjacent       |
| Order must be preserved         | Order must be preserved           |
| Uses `max()` on mismatch        | Usually resets to `0` on mismatch |
| Example: `ACE` from `ABCDE`     | `BCD` from `ABCDE`                |
| DP recurrence differs           | DP recurrence differs             |

### Example

```text
X = ABCDE
Y = ACE
```

LCS:

```text
ACE
```

Length:

```text
3
```

But `ACE` is **not a substring** of `ABCDE`.

# 30. Important Difference from Subset

Students sometimes say:

> "A subsequence is just any subset."

Not exactly.

A subsequence must preserve **relative order**.

For:

```text
ABC
```

`AC` is a subsequence.

But:

```text
CA
```

is not.

# 31. LCS and Edit Distance

LCS is closely related to other string-DP problems.

For example, if insertion/deletion operations are allowed, LCS can help determine how much content is common between two strings.

But:

> **LCS and Edit Distance are different problems and have different objectives and recurrences.**

Do not use the terms interchangeably.

# 32. Common Mistakes

### Mistake 1

Using:

```text
min()
```

instead of:

```text
max()
```

on mismatch.

Correct:

```text
dp[i][j] =
max(
    dp[i-1][j],
    dp[i][j-1]
)
```

---

### Mistake 2

Using:

```text
dp[i][j] = 1 + dp[i-1][j-1]
```

even when characters don't match.

That formula is valid only when:

```text
X[i-1] == Y[j-1]
```

---

### Mistake 3

Confusing substring with subsequence.

---

### Mistake 4

Forgetting the empty-string base case.

```text
dp[0][j] = 0
dp[i][0] = 0
```

---

### Mistake 5

Thinking there is always only one LCS.

There may be multiple different LCS strings with the same maximum length.

# 33. Best Practices

When solving LCS:

### Step 1

Write the two strings.

### Step 2

Define:

```text
dp[i][j]
```

clearly.

### Step 3

Check whether:

```text
X[i-1] == Y[j-1]
```

### Step 4

If equal:

```text
1 + diagonal
```

### Step 5

If different:

```text
max(top, left)
```

### Step 6

The answer is:

```text
dp[m][n]
```

### Step 7

If the actual LCS is required, backtrack from:

```text
dp[m][n]
```

# 40. Interview Questions

### Q1. Why is LCS a Dynamic Programming problem?

Because it has both:

```text
Overlapping Subproblems
```

and:

```text
Optimal Substructure
```

---

### Q2. What is the difference between LCS and Longest Common Substring?

LCS allows gaps between selected characters, while a common substring requires characters to be contiguous.

---

### Q3. Why is the recurrence `1 + dp[i-1][j-1]` used when characters match?

Because the matching character can be included in the common subsequence, and we extend the optimal LCS of the two preceding prefixes by one.

---

### Q4. Why is `max()` used when characters don't match?

Because the optimal LCS must exclude at least one of the two current characters. We therefore evaluate both possibilities and retain the longer subsequence.

---

### Q5. Can the LCS itself be unique?

No. There may be multiple different LCSs having the same maximum length.

---

# 41. Exam-Oriented Answer

### Define LCS.

> The Longest Common Subsequence problem determines the longest sequence that occurs as a subsequence of two given sequences while preserving the relative order of elements. The elements do not need to be contiguous. Dynamic Programming is used because the problem has overlapping subproblems and optimal substructure.

# 43. Final Takeaway

The most important mental model for LCS is:

```text
Compare last characters
        ↓
   ┌────┴────┐
 Same      Different
   ↓           ↓
Diagonal    Max of
 + 1       top & left
```

Remember:

> **Match → diagonal + 1**

> **Mismatch → maximum of top and left**

> **Answer → bottom-right cell**

And if the question asks for the actual sequence:

> **Build the table first, then backtrack.**
