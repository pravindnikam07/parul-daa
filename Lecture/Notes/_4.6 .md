# 2. All-Pairs Shortest Path

Consider a weighted graph:

```text
A ──5──> B
│        │
2        3
│        │
↓        ↓
C ──1──> D
```

A shortest-path algorithm may answer:

> What is the shortest path from A to D?

That is a **single-source shortest-path** question.

But the **All-Pairs Shortest Path** problem asks:

> What is the shortest path between **every pair of vertices**?

For `n` vertices, we want the shortest distance for:

```text
A → B
A → C
A → D
B → A
B → C
...
```

---

# 3. Representation

The graph can be represented using a distance matrix.

For example:

```text
      A   B   C
A     0   4   11
B     ∞   0   2
C     3   ∞   0
```

Where:

* `0` = distance from a vertex to itself.
* A number = direct edge weight.
* `∞` = no direct edge.

---

# 4. Floyd's Algorithm

**Floyd's algorithm** finds the shortest paths between **all pairs of vertices** in a weighted graph.

It uses Dynamic Programming.

The key idea is:

> Gradually allow vertices to be used as intermediate vertices in paths.

---

# 5. DP State

Let:

```text
D[k][i][j]
```

represent:

> The shortest distance from vertex `i` to vertex `j` when only vertices `1...k` are allowed as intermediate vertices.

Instead of storing three dimensions, we can update a 2D matrix in place.

---

# 6. Floyd Recurrence

Suppose vertex `k` is being considered as an intermediate vertex.

There are two possibilities.

### Option 1: Don't use k

```text
dist[i][j]
```

### Option 2: Use k

```text
dist[i][k] + dist[k][j]
```

Therefore:

```text
dist[i][j] =
min(
    dist[i][j],
    dist[i][k] + dist[k][j]
)
```

This is the central formula of Floyd's algorithm.

---

# 7. Why Does This Work?

Suppose we want the shortest path from `i` to `j`.

If the path uses `k`, it can be divided into:

```text
i → k
```

and:

```text
k → j
```

Therefore:

```text
Cost through k
=
dist[i][k] + dist[k][j]
```

We compare this with the existing path:

```text
dist[i][j]
```

and keep the smaller value.

For example:

```text

```

Cost:

```text

```

No improvement.

The matrix remains:

|   |  A |  B |  C |
| - | -: | -: | -: |
| A |  0 |  3 | 10 |
| B |  ∞ |  0 |  2 |
| C |  ∞ |  ∞ |  0 |

## Step 2: Allow B as Intermediate

Consider:

```text
A → B → C
```

Cost:

```text

```

Current:

```text

```

Therefore:

```text

```

Updated matrix:

|   |  A |  B |     C |
| - | -: | -: | ----: |
| A |  0 |  3 | **5** |
| B |  ∞ |  0 |     2 |
| C |  ∞ |  ∞ |     0 |

Therefore:

```text
Shortest distance A → C = 5
```

through B.

# 9. Floyd Algorithm

```text
Floyd-Warshall(dist):

    for k = 0 to n-1:

        for i = 0 to n-1:

            for j = 0 to n-1:

                dist[i][j] =
                    min(
                        dist[i][j],
                        dist[i][k] + dist[k][j]
                    )
```

---

# 10. Java Implementation

```java
public class FloydWarshall {

    static void floydWarshall(int[][] dist) {

        int n = dist.length;
        int INF = 1000000000;

        for (int k = 0; k < n; k++) {

            for (int i = 0; i < n; i++) {

                for (int j = 0; j < n; j++) {

                    if (dist[i][k] != INF &&
                        dist[k][j] != INF) {

                        dist[i][j] = Math.min(
                            dist[i][j],
                            dist[i][k] + dist[k][j]
                        );
                    }
                }
            }
        }
    }

    static void printMatrix(int[][] dist) {

        int INF = 1000000000;

        for (int i = 0; i < dist.length; i++) {

            for (int j = 0; j < dist.length; j++) {

                if (dist[i][j] == INF)
                    System.out.print("INF ");
                else
                    System.out.print(
                        dist[i][j] + " "
                    );
            }

            System.out.println();
        }
    }

    public static void main(String[] args) {

        int INF = 1000000000;

        int[][] dist = {
            {0, 3, 10},
            {INF, 0, 2},
            {INF, INF, 0}
        };

        floydWarshall(dist);

        printMatrix(dist);
    }
}
```

Output:

```text
0 3 5
INF 0 2
INF INF 0
```

# 11. C++ Implementation

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

void floydWarshall(vector<vector<int>>& dist) {

    int n = dist.size();
    const int INF = 1000000000;

    for (int k = 0; k < n; k++) {

        for (int i = 0; i < n; i++) {

            for (int j = 0; j < n; j++) {

                if (dist[i][k] != INF &&
                    dist[k][j] != INF) {

                    dist[i][j] = min(
                        dist[i][j],
                        dist[i][k] + dist[k][j]
                    );
                }
            }
        }
    }
}

int main() {

    const int INF = 1000000000;

    vector<vector<int>> dist = {
        {0, 3, 10},
        {INF, 0, 2},
        {INF, INF, 0}
    };

    floydWarshall(dist);

    for (auto& row : dist) {

        for (int value : row) {

            if (value == INF)
                cout << "INF ";
            else
                cout << value << " ";
        }

        cout << endl;
    }

    return 0;
}
```

# 12. Negative Edge Weights

Floyd-Warshall can handle **negative edge weights**.

Example:

```text
A → B = 4
B → C = -2
```

Then:

```text
A → C = 4 + (-2)
      = 2
```

Therefore, negative edges themselves are not a problem.

---

# 13. Negative Cycle

A **negative cycle** is a cycle whose total weight is negative.

Example:

```text
A → B = 2
B → C = -5
C → A = 1
```

Total:

```text
2 - 5 + 1 = -2
```

The cycle has negative total weight.

In such a graph, a finite shortest path may not exist for affected vertex pairs because the cycle can be traversed repeatedly to make the path cost arbitrarily small.

---

# 14. Detecting a Negative Cycle

After running Floyd-Warshall:

```text
dist[i][i] < 0
```

indicates that vertex `i` is part of, or can participate in, a negative cycle reachable from itself.

Therefore:

```text
for each i:

    if dist[i][i] < 0

        negative cycle exists
```

# 15. Warshall's Algorithm

Warshall's algorithm solves a related but different problem.

It determines:

> **Whether a path exists between every pair of vertices.**

This is called the **Transitive Closure** of a graph.

It does not calculate shortest distances.

---

# 16. Example

Suppose:

```text
A → B
B → C
```

There is no direct edge:

```text
A → C
```

But a path exists:

```text
A → B → C
```

Warshall's algorithm identifies this reachability.

Therefore:

```text
A can reach C = true
```

---

# 17. Warshall DP State

Let:

```text
reach[i][j]
```

represent whether vertex `i` can reach vertex `j`.

The algorithm gradually allows vertices as intermediate vertices.

---

# 18. Warshall Recurrence

For intermediate vertex `k`:

```text
reach[i][j] =
    reach[i][j]
    OR
    (reach[i][k] AND reach[k][j])
```

Meaning:

> `i` can reach `j` either directly/already known, or through `k`.

---

# 19. Warshall Example

Initial graph:

```text
A → B
B → C
```

Initial reachability:

|   |  A |  B |  C |
| - | -: | -: | -: |
| A |  1 |  1 |  0 |
| B |  0 |  1 |  1 |
| C |  0 |  0 |  1 |

When B is considered as an intermediate vertex:

```text
A → B
B → C
```

therefore:

```text
A → C
```

becomes reachable.

Final:

|   |  A |  B |     C |
| - | -: | -: | ----: |
| A |  1 |  1 | **1** |
| B |  0 |  1 |     1 |
| C |  0 |  0 |     1 |

---

# 20. Java Implementation of Warshall

```java
public class Warshall {

    static void warshall(boolean[][] reach) {

        int n = reach.length;

        for (int k = 0; k < n; k++) {

            for (int i = 0; i < n; i++) {

                for (int j = 0; j < n; j++) {

                    reach[i][j] =
                        reach[i][j]
                        ||
                        (reach[i][k]
                        && reach[k][j]);
                }
            }
        }
    }

    public static void main(String[] args) {

        boolean[][] reach = {
            {true, true, false},
            {false, true, true},
            {false, false, true}
        };

        warshall(reach);

        for (boolean[] row : reach) {

            for (boolean value : row) {

                System.out.print(
                    (value ? 1 : 0) + " "
                );
            }

            System.out.println();
        }
    }
}
```

Output:

```text
1 1 1
0 1 1
0 0 1
```

# 21. C++ Implementation of Warshall

```cpp
#include <iostream>
#include <vector>

using namespace std;

void warshall(vector<vector<bool>>& reach) {

    int n = reach.size();

    for (int k = 0; k < n; k++) {

        for (int i = 0; i < n; i++) {

            for (int j = 0; j < n; j++) {

                reach[i][j] =
                    reach[i][j] ||
                    (reach[i][k] &&
                     reach[k][j]);
            }
        }
    }
}

int main() {

    vector<vector<bool>> reach = {
        {true, true, false},
        {false, true, true},
        {false, false, true}
    };

    warshall(reach);

    for (auto& row : reach) {

        for (bool value : row) {

            cout << (value ? 1 : 0)
                 << " ";
        }

        cout << endl;
    }

    return 0;
}
```

# 22. Floyd vs Warshall

This distinction is essential.

| Floyd-Warshall                                 | Warshall                                |
| ---------------------------------------------- | --------------------------------------- |
| Finds shortest distances                       | Finds reachability                      |
| Works with weighted graphs                     | Generally uses connectivity information |
| Uses `min()`                                   | Uses logical `OR`                       |
| Can handle negative edges                      | Edge weights are irrelevant             |
| Detects negative cycles using `dist[i][i] < 0` | Computes transitive closure             |
| Distance matrix                                | Boolean reachability matrix             |

---

# 23. Floyd-Warshall Complexity

There are three nested loops:

```text
k
 i
  j
```

Each runs up to `n`.

Therefore:

### Time Complexity

```text
O(n³)
```

### Space Complexity

```text
O(n²)
```

---

# 24. Warshall Complexity

Similarly:

```text
for k
    for i
        for j
```

Therefore:

### Time Complexity

```text
O(n³)
```

### Space Complexity

```text
O(n²)
```

---

# 25. Floyd-Warshall vs Dijkstra

| Floyd-Warshall                       | Dijkstra                                       |
| ------------------------------------ | ---------------------------------------------- |
| All-pairs shortest path              | Single-source shortest path                    |
| O(n³)                                | Depends on implementation                      |
| Can handle negative edges            | Cannot correctly handle negative edges         |
| Uses DP                              | Greedy                                         |
| Usually convenient with dense graphs | Often useful with non-negative weighted graphs |

---

# 26. Best Practices

When solving Floyd-Warshall:

1. Initialize:

```text
dist[i][i] = 0
```

2. Use `INF` for missing edges.

3. Set direct edge weights correctly.

4. Perform loops in the order:

```text
k → i → j
```

5. Avoid arithmetic such as:

```text
INF + value
```

without checking for `INF`.

6. After the algorithm, check:

```text
dist[i][i] < 0
```

for negative cycles.

# 32. Summary

* **All-Pairs Shortest Path** finds shortest paths between every pair of vertices.
* **Floyd-Warshall** uses Dynamic Programming and considers each vertex as a possible intermediate vertex.
* Its recurrence is:

```text
dist[i][j] =
min(dist[i][j],
    dist[i][k] + dist[k][j])
```

* Floyd-Warshall can handle negative edge weights but not graphs containing reachable negative cycles as ordinary finite shortest-path problems.
* **Warshall's algorithm** computes transitive closure rather than shortest distances.
* Both algorithms have:

```text
Time  = O(n³)
Space = O(n²)
```

* The most important distinction is:

```text
Floyd-Warshall → shortest paths
Warshall       → reachability
```
