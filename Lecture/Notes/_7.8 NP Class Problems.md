# Unit 7: String Matching & NP Completeness

## Topic 7.8 — NP Class Problems

## 1. Introduction

**NP** stands for **Nondeterministic Polynomial Time**.

In simple terms:

> **NP is the class of decision problems for which a given solution can be verified in polynomial time.**

The important point is:

**NP does not mean "Not Polynomial."**

---

# 2. Decision Problem

NP classification is mainly applied to **decision problems**.

A decision problem has only two possible answers:

```text
YES
NO
```

### Example

Instead of asking:

> Find a Hamiltonian cycle.

we ask:

> Does this graph contain a Hamiltonian cycle?

Answer:

```text
YES
```

or:

```text
NO
```

---

# 3. Verification in NP

Suppose someone gives us a proposed solution to a problem.

If we can verify that solution in polynomial time, the problem can belong to NP.

The basic process is:

```text
Problem
   ↓
Proposed Solution
   ↓
Verify Solution
   ↓
Polynomial Time?
   ↓
YES → Problem is in NP
```

---

# 4. Example: Hamiltonian Cycle

Consider:

```text
A ----- B
|       |
|       |
D ----- C
```

Suppose someone gives:

```text
A → B → C → D → A
```

We can verify:

1. Every vertex appears.
2. No vertex is repeated.
3. Every consecutive pair has an edge.
4. The cycle returns to A.

These checks can be performed in polynomial time.

Therefore:

$$
\boxed{\text{Hamiltonian Cycle} \in NP}
$$

---

# 5. Certificate

A **certificate** is a proposed solution that can be checked by a verifier.

For Hamiltonian Cycle:

```text
A → B → C → D → A
```

is the certificate.

The verifier checks whether it is a valid Hamiltonian cycle.

```text
Certificate
     ↓
Verifier
     ↓
Valid?
 /    \
YES    NO
```

---

# 6. Verifier

A **verifier** is an algorithm that checks whether a proposed certificate is a valid solution.

For example:

```text
Certificate:
A → B → C → D → A
```

Verifier checks:

```text
Are all vertices present?       ✓
Are vertices appropriately unique? ✓
Do required edges exist?        ✓
Does it return to A?            ✓
```

Therefore:

```text
Valid Hamiltonian Cycle
```

---

# 7. P and NP

Recall:

### P

A problem can be:

```text
Solved efficiently
```

### NP

A proposed solution can be:

```text
Verified efficiently
```

Therefore:

$$
\boxed{P\subseteq NP}
$$

Every problem that can be solved efficiently can also have its solution verified efficiently.

---

# 8. Example: Subset Sum

Consider:

```text
Numbers = {3, 5, 7, 10}
Target = 15
```

Question:

> Is there a subset whose sum is 15?

Suppose someone gives:

```text
5 + 10 = 15
```

We can verify:

```text
5 + 10
= 15
```

in polynomial time.

Therefore, the **decision version of Subset Sum belongs to NP**.

---

# 9. Example: 0/1 Knapsack

Suppose:

```text
Items:

Item 1 → Weight 2, Value 10
Item 2 → Weight 3, Value 15
Item 3 → Weight 4, Value 20

Capacity = 5
```

A decision version could ask:

> Is there a selection of items whose total weight is at most 5 and whose total value is at least 25?

Suppose someone proposes:

```text
Item 1 + Item 2
```

Check:

```text
Total weight = 2 + 3 = 5
Total value  = 10 + 15 = 25
```

Both conditions are satisfied.

Therefore, the proposed solution can be verified efficiently.

---

# 10. NP Does Not Mean Difficult to Verify

The important distinction is:

```text
Finding a solution
        ≠
Verifying a solution
```

For some NP problems:

```text
Finding solution → potentially difficult
Verifying solution → polynomial time
```

This distinction is central to NP.

---

# 11. NP Does Not Mean "Not Polynomial"

This is one of the most common misconceptions.

Incorrect:

> NP means problems that cannot be solved in polynomial time.

Correct:

> NP is the class of problems whose proposed solutions can be verified in polynomial time.

Whether every NP problem can also be **solved** in polynomial time is the famous:

$$
\boxed{P\text{ vs }NP}
$$

question.

---

# 12. P Is Inside NP

Consider:

```text id="2aq5p1"
        NP
 ┌─────────────────┐
 │                 │
 │      P          │
 │   ┌───────┐     │
 │   │       │     │
 │   └───────┘     │
 │                 │
 └─────────────────┘
```

The important relationship is:

$$
\boxed{P\subseteq NP}
$$

This means:

> Every problem in P is also in NP.

---

# 13. Why P Problems Are in NP

Suppose a problem has a polynomial-time algorithm:

$$
O(n^2)
$$

Then we can simply run that algorithm to obtain the answer.

Therefore, we can also verify the answer within polynomial time.

Hence:

$$
P\subseteq NP
$$

---

# 14. Examples of Problems in NP

Some well-known decision problems in NP include:

* Hamiltonian Cycle
* Subset Sum
* 0/1 Knapsack decision problem
* Traveling Salesman decision problem
* Graph Coloring decision problem
* SAT

For this syllabus, the important example is:

$$
\boxed{\text{Hamiltonian Cycle}}
$$

---

# 15. Hamiltonian Cycle Verification

Suppose a graph contains `n` vertices.

Candidate certificate:

```text
v1 → v2 → v3 → ... → vn → v1
```

Verification:

### Step 1

Check that exactly `n` vertices are listed.

### Step 2

Check that each vertex occurs exactly once.

### Step 3

Check that every consecutive pair has an edge.

### Step 4

Check that:

```text
vn → v1
```

is also an edge.

All these operations can be performed in polynomial time.

Therefore:

$$
\boxed{\text{Hamiltonian Cycle}\in NP}
$$

---

# 16. NP vs NP-Complete

These terms should not be confused.

### NP

A problem whose proposed solution can be verified in polynomial time.

### NP-Complete

A problem that:

1. Belongs to NP.
2. Is NP-hard.

Therefore:

$$
\boxed{\text{NP-Complete}\subseteq NP}
$$

and:

$$
\boxed{\text{NP-Complete} = NP + NP\text{-Hard}}
$$

---

# 17. NP vs P vs NP-Complete

| Feature                        | P               | NP                | NP-Complete         |
| ------------------------------ | --------------- | ----------------- | ------------------- |
| Polynomial-time solution known | Yes             | Not necessarily   | Not currently known |
| Polynomial-time verification   | Yes             | Yes               | Yes                 |
| NP-hard                        | Not necessarily | Not necessarily   | Yes                 |
| Example                        | BFS             | Hamiltonian Cycle | Hamiltonian Cycle   |

Remember that a problem can be both in P and NP.

---

# 18. Important: Optimization vs Decision Version

Complexity classes such as P and NP are defined primarily using **decision problems**.

### Optimization

> Find the shortest Hamiltonian cycle.

### Decision

> Is there a Hamiltonian cycle of length at most `K`?

The second question has:

```text
YES / NO
```

and is the form used in NP classification.

---

# 19. Example: Traveling Salesman Problem

Optimization version:

> Find the minimum-cost tour visiting every city exactly once.

Decision version:

> Is there a tour visiting every city exactly once with total cost ≤ K?

The decision version is an NP problem and is NP-Complete.

---

# 20. Example: Graph Coloring

Suppose we have a graph and `k` colors.

Decision problem:

> Can the graph be colored using at most `k` colors so that adjacent vertices have different colors?

A proposed coloring can be verified by checking every edge.

For every edge:

```text
Color(u) != Color(v)
```

If all edges satisfy this condition, the proposed coloring is valid.

Therefore, the problem is in NP.

---

# 21. Verification Example

Suppose:

```text
Graph:

A ----- B
|       |
|       |
C ----- D
```

and proposed coloring:

```text
A = Red
B = Blue
C = Blue
D = Red
```

Check every edge:

```text
A-B → Red ≠ Blue ✓
A-C → Red ≠ Blue ✓
B-D → Blue ≠ Red ✓
C-D → Blue ≠ Red ✓
```

The certificate is valid.

---

# 22. NP Verification Pattern

For many NP problems, the process looks like:

```text
Input
  +
Certificate
  ↓
Verifier
  ↓
Check constraints
  ↓
Polynomial time
  ↓
YES / NO
```

This is the key concept students should remember.

---

# 23. Relation to NP-Completeness

To prove a problem is NP-Complete:

### Step 1

Show:

$$
B\in NP
$$

### Step 2

Show that a known NP-Complete problem can be reduced to B:

$$
A\leq_p B
$$

Then:

```text
B ∈ NP
+
B is NP-Hard
↓
B is NP-Complete
```

---

# 24. Common Mistakes

### Mistake 1

> NP means "Not Polynomial."

❌ Incorrect.

---

### Mistake 2

> NP problems cannot be solved in polynomial time.

❌ Not established.

Some NP problems are in P.

The open question is whether:

$$
P=NP
$$

---

### Mistake 3

> NP means every solution takes exponential time to verify.

❌ Incorrect.

The defining idea is that a proposed solution can be verified in polynomial time.

---

### Mistake 4

Confusing NP with NP-Complete.

```text
NP
↓
Large class of decision problems
```

while:

```text
NP-Complete
↓
Problems that are both NP and NP-Hard
```
