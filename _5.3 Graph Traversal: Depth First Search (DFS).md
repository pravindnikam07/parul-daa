# Unit 5: Exploring Graphs

## Topic 5.3 — Graph Traversal: Depth First Search (DFS)

## 1. Introduction

**Graph traversal** means visiting the vertices of a graph systematically.

Two important graph traversal techniques are:

1. **Depth First Search (DFS)**
2. **Breadth First Search (BFS)**

In this topic, we study **DFS**.

### Definition

**Depth First Search (DFS)** is a graph traversal algorithm that explores a graph by going as deep as possible along one path before backtracking.

DFS uses:

* **Stack**, or
* **Recursion** (which internally uses the call stack)

---

# 2. Basic Idea of DFS

Consider the graph:

```text
       0
      / \
     1   2
    / \
   3   4
```

Starting from vertex `0`, DFS can visit:

```text
0 → 1 → 3 → 4 → 2
```

The exact traversal order can vary depending on the order in which adjacent vertices are stored.

### Main idea

```text
Start
  ↓
Visit current vertex
  ↓
Visit an unvisited adjacent vertex
  ↓
Continue deeper
  ↓
No unvisited neighbor?
  ↓
Backtrack
```

---

# 3. Why Do We Need a Visited Array?

A graph can contain cycles.

Example:

```text
0 ----- 1
|       |
|       |
3 ----- 2
```

If we do not keep track of visited vertices, traversal may repeatedly move:

```text
0 → 1 → 2 → 3 → 0 → 1 → ...
```

Therefore, DFS maintains:

```text
visited[]
```

Initially:

```text
visited[i] = false
```

When a vertex is visited:

```text
visited[i] = true
```

---

# 4. DFS Algorithm

### Algorithm: DFS

```text
DFS(G, v)

1. Mark v as visited.
2. Process v.
3. For every adjacent vertex u of v:
      If u is not visited:
          DFS(G, u)
```

The recursive call allows DFS to continue deeper into the graph.

# 5. Dry Run

Consider:

```text
       0
      / \
     1   2
    / \
   3   4
```

Adjacency list:

```text
0 → 1, 2
1 → 0, 3, 4
2 → 0
3 → 1
4 → 1
```

Start DFS from `0`.

### Step 1

Visit `0`.

```text
Visited: {0}
DFS: 0
```

Go to `1`.

### Step 2

Visit `1`.

```text
Visited: {0, 1}
DFS: 0 → 1
```

Go to `3`.

### Step 3

Visit `3`.

```text
Visited: {0, 1, 3}
DFS: 0 → 1 → 3
```

`3` has no unvisited neighbor.

Backtrack to `1`.

### Step 4

From `1`, visit `4`.

```text
Visited: {0, 1, 3, 4}
DFS: 0 → 1 → 3 → 4
```

Backtrack to `0`.

### Step 5

From `0`, visit `2`.

```text
Visited: {0, 1, 2, 3, 4}
DFS: 0 → 1 → 3 → 4 → 2
```

Final traversal:

```text
0 1 3 4 2
```

# 6. DFS Using Recursion — Java

```java
import java.util.*;

public class DFSExample {

    static void dfs(
            int vertex,
            ArrayList<ArrayList<Integer>> graph,
            boolean[] visited) {

        // Mark current vertex as visited
        visited[vertex] = true;

        // Process the vertex
        System.out.print(vertex + " ");

        // Visit all unvisited neighbors
        for (int neighbor : graph.get(vertex)) {

            if (!visited[neighbor]) {
                dfs(neighbor, graph, visited);
            }
        }
    }

    public static void main(String[] args) {

        int vertices = 5;

        ArrayList<ArrayList<Integer>> graph =
                new ArrayList<>();

        for (int i = 0; i < vertices; i++) {
            graph.add(new ArrayList<>());
        }

        // Undirected graph
        graph.get(0).add(1);
        graph.get(1).add(0);

        graph.get(0).add(2);
        graph.get(2).add(0);

        graph.get(1).add(3);
        graph.get(3).add(1);

        graph.get(1).add(4);
        graph.get(4).add(1);

        boolean[] visited = new boolean[vertices];

        System.out.print("DFS Traversal: ");
        dfs(0, graph, visited);
    }
}
```

### Output

```text
DFS Traversal: 0 1 3 4 2
```

# 7. DFS Using Recursion — C++

```cpp
#include <iostream>
#include <vector>
using namespace std;

void dfs(
    int vertex,
    vector<vector<int>>& graph,
    vector<bool>& visited) {

    // Mark current vertex as visited
    visited[vertex] = true;

    // Process the vertex
    cout << vertex << " ";

    // Visit all unvisited neighbors
    for (int neighbor : graph[vertex]) {

        if (!visited[neighbor]) {
            dfs(neighbor, graph, visited);
        }
    }
}

int main() {

    int vertices = 5;

    vector<vector<int>> graph(vertices);

    // Undirected graph
    graph[0].push_back(1);
    graph[1].push_back(0);

    graph[0].push_back(2);
    graph[2].push_back(0);

    graph[1].push_back(3);
    graph[3].push_back(1);

    graph[1].push_back(4);
    graph[4].push_back(1);

    vector<bool> visited(vertices, false);

    cout << "DFS Traversal: ";

    dfs(0, graph, visited);

    return 0;
}
```

### Output

```text
DFS Traversal: 0 1 3 4 2
```

# 8. DFS Using Stack

DFS can also be implemented explicitly using a **stack** instead of recursion.

### Algorithm

```text
DFS using Stack

1. Create an empty stack.
2. Push the starting vertex.
3. While stack is not empty:
      a. Pop a vertex.
      b. If it is not visited:
            Mark it visited.
            Process it.
            Push its unvisited neighbors.
```

Example:

```text
Stack
 ↓
[0]
```

Pop `0` and push its neighbors.

```text
[2, 1]
```

The last inserted vertex is processed first because a stack follows **LIFO**:

```text
Last In → First Out
```

---

# 9. Recursive DFS vs Iterative DFS

| Feature        | Recursive DFS                           | Stack-based DFS             |
| -------------- | --------------------------------------- | --------------------------- |
| Data structure | Call stack                              | Explicit stack              |
| Implementation | Simpler                                 | More control                |
| Code           | Shorter                                 | Slightly longer             |
| Risk           | Deep recursion can cause stack overflow | Avoids recursive-call depth |
| Principle      | DFS                                     | DFS                         |

For learning and basic implementations, **recursive DFS is usually easier to understand**.

# 10. DFS for Disconnected Graphs

A graph may contain multiple disconnected components.

Example:

```text
0 ----- 1       2 ----- 3
```

Starting DFS from `0` only visits:

```text
0 1
```

Vertices `2` and `3` remain unvisited.

To visit the **entire graph**, run DFS from every unvisited vertex.

### Algorithm

```text
for each vertex v:
    if v is not visited:
        DFS(v)
```

### Java

```java
static void dfs(int vertex,
                ArrayList<ArrayList<Integer>> graph,
                boolean[] visited) {

    visited[vertex] = true;
    System.out.print(vertex + " ");

    for (int neighbor : graph.get(vertex)) {
        if (!visited[neighbor]) {
            dfs(neighbor, graph, visited);
        }
    }
}
```

Then:

```java
for (int i = 0; i < vertices; i++) {
    if (!visited[i]) {
        dfs(i, graph, visited);
    }
}
```

This ensures that every connected component is explored.

# 11. Time Complexity

Using an **adjacency list**:

```text
Time Complexity = O(V + E)
```

where:

* `V` = number of vertices
* `E` = number of edges

Why?

Each vertex is visited at most once:

```text
O(V)
```

Each edge is examined during traversal:

```text
O(E)
```

Therefore:

```text
O(V + E)
```

### Space Complexity

The graph itself requires:

```text
O(V + E)
```

and DFS additionally uses:

```text
O(V)
```

for the visited array and recursion stack in the worst case.

DFS is commonly used for:

* Graph traversal

* Path finding
* Topological sorting
* Solving maze-like problems
* Exploring state spaces

# 13. Important Points

### Point 1: DFS does not necessarily produce a unique traversal

The traversal depends on the order of adjacent vertices.

For example:

```text
0 → 1, 2
```

may produce:

```text
0 1 3 4 2
```

while changing the adjacency order can produce:

```text
0 2 1 4 3
```

Both can be valid DFS traversals.

### Point 2: Mark vertices as visited

Always use:

```text
visited[]
```

to prevent repeated processing and infinite traversal in cyclic graphs.

### Point 3: DFS is not the same as shortest-path search

DFS explores deeply first. It does **not generally guarantee the shortest path** in an unweighted graph.

# 16. Quick Revision

```text
DFS
 │
 ├── Start from a vertex
 │
 ├── Mark it visited
 │
 ├── Process it
 │
 ├── Go to an unvisited neighbor
 │
 ├── Continue deeper
 │
 └── Backtrack when necessary
```

### Key Points

* DFS = **Depth First Search**
* Uses **recursion or stack**
* Uses a **visited array**
* Goes deep before backtracking
* Time complexity with adjacency list: **O(V + E)**
* Works with both directed and undirected graphs
* Can be used to explore disconnected graphs by starting DFS from every unvisited vertex.
